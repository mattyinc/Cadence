# Cadence for Android

Read and listen to your Cadence library on an Android tablet — the same books, from the same place
(OneDrive › Apps › Cadence) as the Apple TV app. Add books with **Cadence Studio** on the Mac.

- Books and Audiobooks shelves, chapter list, "Continue" where you left off
- Reader: one sentence at a time with the word-by-word reveal, the whole chapter, or a full-screen card
- Audiobooks: text follows the narration (streamed from OneDrive)
- Reading style: fonts, size, margins, line spacing; parchment page; Dark / Light theme
- Dictionary look-up (English), sleep timer, speed

## Install
Every push to `main` builds an APK on GitHub Actions and publishes it under **Releases**.
Download the newest `Cadence-1.0.N.apk` on the tablet and open it. Builds are signed with the same key,
so each one installs over the previous one.

## Gestures in the reader
Tap: show/hide controls · swipe left/right: next/previous sentence · swipe up: sentence ↔ whole chapter ·
swipe down: controls · Back: hide controls, then close the book.
